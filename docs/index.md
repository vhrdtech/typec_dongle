# Donguru — ドングル**

Donguru is a USB-Type-C dongle featuring a USB Hub, USART/I2C/GPIO/ADC, a power
switch and a power meter.

## Features

- **USB Hub** — expand a single USB-Type-C port into multiple downstream ports.
- **USART / I2C / GPIO / ADC** — general-purpose interfaces for prototyping
  and debugging.
- **Power switch** — enable or disable power to downstream devices.
- **Power meter** — monitor voltage and current draw.
